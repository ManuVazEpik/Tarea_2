# Práctica Interfaces Avanzadas con Threads (JavaFX + Maven)

Dos proyectos independientes: ej31 (Conteo) y ej32 (La liebre y la tortuga).

## Cómo correrlos en Visual Studio Code
1. Instala el JDK 17 o superior y la extensión "Extension Pack for Java" (Microsoft).
2. File > Open Folder... y abre la carpeta de UN ejercicio (ej31 o ej32).
3. Espera a que la extensión importe el proyecto Maven (descarga JavaFX; necesita internet la primera vez).
4. Abre src/main/java/.../Launcher.java y pulsa "Run" sobre el método main.
   Alternativa en terminal (si tienes Maven):  mvn javafx:run
